# Voxel Slice Pre-Processor

This project is a high-performance voxel manipulation tool designed to pre-process slice files for mSLA/SLA resin 3D printers. It provides a foundational framework for editing 3D printing outputs by leveraging a powerful combination of CPU and GPU processing.

## Core Technologies

- **Primary Language:** Python 3.10+
- **Voxel Engine:** OpenVDB 12.1.0
- **GPU Compute & Rendering:** ModernGL
- **GPU Voxel Structure:** nVidia NanoVDB
- **GUI Framework:** PySide6
- **CPU Acceleration:** Numba
- **Testing:** pytest

This repository contains the foundational modules, documentation, and architectural framework for the tool. See `SETUP.md` for detailed instructions on how to set up the development environment.
